# 🎓 Student Performance Classification

A beginner-friendly **Machine Learning** project that predicts whether a student's performance
will be **Low, Medium or High**, with a web app built using **Streamlit**.

## 1. Problem Statement
Teachers want to identify weak students early. Given a student's study habits (study hours,
attendance, previous marks, assignments, sleep) and background (parental education, internet
access, extracurricular activities), we classify the student into one of three classes.

- **Type of ML:** Supervised learning -> Multi-class classification
- **Input (X):** 9 features  |  **Output (y):** `performance` = Low / Medium / High

## 2. Dataset
`data/student_data.csv` - 1000 students, 10 columns.
The data is **synthetic** (generated by `generate_dataset.py`) because real student records are private.
Results depend on how the data was generated, so accuracy here shows the *method* works, not that
it predicts real students. You may replace the CSV with a real dataset (keep the same column names).

| Column | Meaning |
|---|---|
| gender | Male / Female |
| study_hours_per_day | 0 - 10 |
| attendance_percent | 35 - 100 |
| previous_marks | last exam marks out of 100 |
| assignments_completed_percent | 10 - 100 |
| sleep_hours | 3.5 - 10 |
| parental_education | High School / Graduate / Post Graduate |
| internet_access | Yes / No |
| extracurricular | Yes / No |
| **performance** | **Target:** Low / Medium / High |

## 3. Methodology
1. **Load data** with pandas.
2. **Pre-processing:** StandardScaler for numbers, OneHotEncoder for text columns (inside a scikit-learn `Pipeline`).
3. **Train/Test split:** 80% / 20% (stratified, so every class is represented equally).
4. **Algorithms compared:** Logistic Regression, Decision Tree (max depth 5), Random Forest (200 trees).
5. **Evaluation:** Accuracy, Precision, Recall, F1-score, Confusion Matrix, 5-fold Cross-Validation.
6. **Prediction:** the best model is used in the web app.

## 4. Results (on the included dataset)
| Model | Accuracy | F1 |
|---|---|---|
| Logistic Regression | 0.695 | 0.697 |
| Decision Tree | 0.605 | 0.606 |
| Random Forest | 0.680 | 0.680 |

Logistic Regression performed best because the data was built from a mostly linear formula.
Most important features: previous marks, study hours, attendance.
(Run `python train_model.py` to reproduce these numbers and save charts.)

## 6. Run on your computer
```bash
pip install -r requirements.txt
python train_model.py        # optional: see results in terminal
streamlit run app.py         # opens the web app in browser
```

## 7. Deploy FREE on Streamlit Community Cloud
1. Create a free account on https://github.com and make a **new public repository** (e.g. `student-performance-classification`).
2. Click **Add file -> Upload files**, drag in ALL files and folders from this project
   (`app.py`, `ml_pipeline.py`, `requirements.txt`, `data/`, etc.), then **Commit changes**.
   Make sure `app.py` and `requirements.txt` are in the repo's main (root) folder.
3. Go to https://share.streamlit.io and sign in with GitHub.
4. Click **Create app** -> choose your repository, branch `main`, main file path `app.py`.
5. Click **Deploy**. After 1-3 minutes you get a public link like `https://yourname-student-performance.streamlit.app`.
